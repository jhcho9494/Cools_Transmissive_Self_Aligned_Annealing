# 쿨스 반도체 투과형 자기정렬 어닐 플랫폼

## 표면을 가열하지 말고, 매립된 표적을 직접 활성화합니다

> **종래 레이저 어닐은 광이 처음 닿는 표면을 가열한 뒤 열이 표적까지 확산되기를 기다립니다.**  
> **쿨스는 밴드갭 이하 광을 반도체 몸체에 통과시키고, 실제 활성화가 필요한 후면 접점·도핑층·손상층에서 직접 열을 발생시킵니다.**

## 전략적 제안

쿨스는 선단 반도체와 수직형 전력반도체 제조를 위한 **재료 중립형 투과입사 자기정렬 어닐 플랫폼**을 제안합니다.

이 기술은 또 하나의 표면 레이저 어닐이 아닙니다.  
이중빔 캐리어 생성 방식도 아닙니다.  
예열광에 의존하는 열확산 공정도 아닙니다.

> **반도체 몸체는 광학창이 되고, 매립된 표적층은 스스로 히터가 됩니다.**

```text
밴드갭 이하 광펄스
→ 반도체 몸체 투과
→ 후면 금속·고농도 도핑층·손상층에서 선택흡수
→ 발열 피크가 필요한 활성화 위치에 자기정렬
→ 전면 소자 온도는 손상 허용치 이하 유지
```

흡수 프로파일이 곧 발열 위치를 결정하므로, 재료스택이 설계된 뒤에는 매립계면에 대한 별도 광학정렬이 필요하지 않습니다.

## 왜 이 아키텍처가 필요한가

수직형 소자는 전면의 게이트·소스·에미터·배선이 이미 완성된 후에도 후면에서 고온 반응이 필요합니다.

종래 공정은 다음의 충돌을 피하기 어렵습니다.

```text
후면 활성화 온도 상승
→ 옴접점·도펀트 활성화 향상
→ 완성된 전면으로 열확산 증가
→ 게이트·유전체·금속 손상 위험 증가
```

쿨스는 광 입사면과 열 발생 표적면을 분리하여 이 충돌을 해소합니다.

> **웨이퍼 두께는 가열되어야 할 재료가 아니라, 광투과 경로이자 전면 보호용 열완충 거리로 사용됩니다.**

## 핵심 작동원리

### TRANSMIT — 투과

반도체 밴드갭보다 낮은 광자 에너지를 선택하여 반도체 몸체의 밴드간 흡수를 억제합니다.

### SELECT — 선택흡수

후면 접점 형성층, 고농도 도핑영역, 이온주입 손상영역 또는 결함이 풍부한 영역이 주변 반도체보다 강하게 흡수하도록 설계합니다.

### SELF-ALIGN — 자기정렬

가장 강하게 흡수되는 위치가 가장 강하게 발열하는 위치가 됩니다. 재료·도핑·손상 프로파일이 활성화 영역을 직접 결정합니다.

### CONTAIN — 열가둠

펄스폭으로 열확산 길이를 제어하여 열영향을 표적계면 인근에 국소화합니다. Silicon-On-Insulator(SOI) 구조에서는 Buried Oxide(BOX, 매립 산화막)가 광학 저흡수 경계와 열단열 경계로 동시에 작동합니다.

### ACTIVATE — 활성화

전면 소자의 열손상을 억제하면서 후면 옴접점, 필드스톱층, 컬렉터층 또는 SOI 상부 반도체층을 형성·활성화합니다.

## 하나의 광학 플랫폼으로 여러 반도체 재료에 적용

특허 포트폴리오는 다음을 하나의 공통 아키텍처로 묶습니다.

- 실리콘(Si) 수직형 Insulated Gate Bipolar Transistor(IGBT, 절연 게이트 양극성 트랜지스터) 후면 활성화
- Silicon Carbide(SiC, 탄화규소) 후면 옴접점
- Gallium Nitride(GaN, 질화갈륨) 후면 옴접점
- Gallium Oxide(Ga₂O₃, 산화갈륨) 후면 옴접점
- 재료 중립형 후면 접점 어닐
- BOX의 광학·열적 경계를 이용한 SOI 상부층 어닐

> **하나의 광학 원리, 여러 반도체 재료, 필요한 층에서만 열 발생.**

## Si IGBT — 이온주입 프로파일이 스스로 어닐 마스크가 됩니다

수직형 IGBT에서는 밴드갭 이하 광이 저농도 드리프트층을 통과하고, 고농도 또는 이온주입 손상을 가진 필드스톱층과 컬렉터층에서 우세하게 흡수됩니다.

대표 흡수 메커니즘은 다음을 포함합니다.

- Free-Carrier Absorption(FCA, 자유 캐리어 흡수)
- 이온주입 손상 흡수
- 결함준위 흡수
- 도펀트 관련 흡수
- 온도 상승에 따른 흡수 증가

```text
저농도 드리프트층: 광투과 + 열완충
고농도·손상 후면층: 선택흡수 + 도펀트 활성화
```

따라서 활성화 깊이는 표면에서 시작된 열확산만으로 정해지지 않고, 도핑·손상 프로파일에 자기정렬됩니다. fileciteturn96file0

## SiC — 전면을 고온 사이클에 넣지 않고 후면 고온 접점화학을 형성

수직형 SiC 후면 옴접점은 금속 실리사이드·카바이드 반응을 위해 높은 국부온도가 필요합니다.

쿨스는 근적외선 또는 단파장 적외선 광을 SiC 몸체에 통과시킨 뒤, 후면 접점 형성층 또는 그 계면에 흡수와 발열을 집중시킵니다.

이 플랫폼은 다음 요구를 동시에 겨냥합니다.

- 높은 국부 접점반응 온도
- 낮은 전면 열노출
- 박막 기판 적합성
- 기판저항 저감
- 후면 접촉저항 저감

> **광 입사면이 아니라 SiC 후면 접점계면에 발열 피크를 형성합니다.**

## GaN — 광폭밴드갭 몸체를 광학창으로 사용

수직형 GaN에서는 밴드갭 이하 광이 자립형 GaN 기판을 통과하고, 후면 접점 형성 금속스택에서 흡수될 수 있습니다.

GaN 몸체는 주 광투과 경로가 되고, 금속 또는 금속–GaN 반응영역이 열 표적이 됩니다.

GaN-on-Si 구조에서는 Si 핸들기판 제거 또는 파장·흡수율 정합을 통해 후면 접점영역의 우세 발열을 유지하는 구조까지 포함합니다.

> **GaN 기판은 열원이 아니라 광학창이 됩니다.**

## Ga₂O₃ — 광투과성과 열가둠을 동시에 활용

Ga₂O₃는 초광폭 밴드갭과 낮은 열확산 특성을 동시에 가집니다.

쿨스 구조에서는:

- Ga₂O₃ 몸체가 밴드갭 이하 광을 투과시키고
- 후면 접점 형성층이 선택적으로 흡수·발열하며
- 낮은 열확산이 전면 방향 열침투를 억제하고
- 결정방위별 광흡수·열전도 이방성이 공정 정합 변수로 사용됩니다.

> **Ga₂O₃는 광만 통과시키는 것이 아니라, 후면 접점에 열을 가두는 데에도 기여합니다.**

## SOI — BOX를 전기절연층이 아니라 어닐 케이지로 사용

SOI 구조에서 BOX는 단순한 전기적 절연층이 아닙니다.

두 가지 능동 공정기능을 수행합니다.

- **광학 경계:** 선택 파장에 대한 낮은 흡수
- **열 경계:** 핸들기판으로의 열유출을 억제하는 낮은 열전도

상부 반도체층이 BOX보다 더 강하게 흡수하고, BOX는 발생한 열을 상부층에 가둡니다.

> **BOX는 광흡수의 경계이자 열활성화의 가둠 경계가 됩니다.**

별도의 캐리어 생성빔이나 예열빔 없이 단일 펄스로 상부층 발열을 시작하고, 박막 및 3차원 적층 구조를 선택적으로 활성화하는 방향입니다. fileciteturn96file1

## 종래 방식과 쿨스 방식

| 공정축 | 종래 표면·이중빔 어닐 | 쿨스 투과형 자기정렬 어닐 |
|---|---|---|
| 광 입사 | 가열 표면과 같은 면 | 반대면 또는 투과경로 |
| 주 흡수 | 광이 처음 닿는 표면 | 후면 접점·도핑층·손상층 |
| 열 위치 | 표면흡수와 열확산 중심 | 재료·도핑·손상 선택성 중심 |
| 정렬 | 광학 위치제어·표면형상 | 재료스택 자기정렬 |
| 박막화 시 전면보호 | 점점 어려움 | 펄스폭·입사면–표적면 분리로 제어 |
| 광학장치 | 엑시머·그린·예열·이중빔 | 단일 밴드갭 이하 펄스 가능 |
| 재료 범위 | 재료별 개별 최적화 | Si·SiC·GaN·Ga₂O₃·SOI 공통 플랫폼 |
| 기능층 | 별도 흡수층 추가 가능 | 기존 배리어·접점층을 흡수체로 겸용 가능 |

- 전면 공정 완료 후 열예산 저감

- 기판저항과 접촉저항 동시 저감
- 전면 게이트·유전체·배선 손상 억제

# Cools 半导体透射式自对准退火平台

## 停止加热表面，直接激活埋入目标

> **传统激光退火首先加热光束落下的表面，再等待热扩散到真正的目标。**  
> **Cools 让亚带隙光穿过半导体本体，并在真正需要激活的背面接触、掺杂层或损伤层直接产生热。**

## 战略方案

Cools 面向先进半导体与垂直功率器件制造提出 **材料中立的透射入射自对准退火平台**。

这不是另一种表面激光退火。  
不是双光束载流子生成方案。  
也不是依赖预热光的热扩散工艺。

> **半导体本体成为光学窗口，埋入目标层成为自身的加热器。**

```text
亚带隙光脉冲
→ 穿过半导体本体
→ 在背面金属、高掺杂层或损伤层选择性吸收
→ 热峰自动对准真正需要激活的位置
→ 正面器件保持在热损伤限值以下
```

吸收分布本身决定发热位置。一旦材料堆栈完成设计，就不再需要对埋入界面进行额外光学对准。

## 为什么行业需要这种架构

垂直器件在正面栅极、源极、发射极和金属布线已经完成后，仍然需要在背面产生高温反应。

传统工艺存在根本冲突：

```text
提高背面激活温度
→ 改善欧姆接触或掺杂激活
→ 更多热扩散至已完成的正面
→ 栅极、介质与金属损伤风险上升
```

Cools 通过分离光学入射面与热目标面来打破这一冲突。

> **晶圆厚度不再只是需要加热的材料，而是光传输路径和保护正面的热缓冲距离。**

## 核心工作原理

### TRANSMIT — 透射

选择光子能量低于半导体带隙的光，使半导体本体中的带间吸收受到抑制。

### SELECT — 选择吸收

让背面接触形成层、高掺杂区、离子注入损伤区或富缺陷区比周围半导体更强地吸收。

### SELF-ALIGN — 自对准

最强吸收位置成为最强发热位置。材料、掺杂与损伤分布直接定义激活区域。

### CONTAIN — 热约束

通过脉冲宽度控制热扩散长度，使热影响局限在目标界面附近。在 Silicon-On-Insulator（SOI，绝缘体上硅）结构中，Buried Oxide（BOX，埋氧层）同时构成低吸收光学边界与热绝缘边界。

### ACTIVATE — 激活

在抑制正面器件热损伤的同时，形成或激活背面欧姆接触、场截止层、集电极层或 SOI 上部半导体层。

## 一个光学平台覆盖多种半导体材料

专利组合以同一架构覆盖：

- Silicon（Si）垂直 Insulated Gate Bipolar Transistor（IGBT，绝缘栅双极晶体管）背面激活；
- Silicon Carbide（SiC，碳化硅）背面欧姆接触；
- Gallium Nitride（GaN，氮化镓）背面欧姆接触；
- Gallium Oxide（Ga₂O₃，氧化镓）背面欧姆接触；
- 材料中立型背面接触退火；
- 利用 BOX 光学和热边界的 SOI 上层退火。

> **一个光学原理，多种半导体材料，只在需要激活的层产生热。**

---

## Si IGBT — 离子注入分布成为自身的退火掩模

在垂直 IGBT 中，亚带隙光穿过低掺杂漂移层，并在高掺杂或离子注入损伤的场截止层和集电极层中优先吸收。

代表性吸收机制包括：

- Free-Carrier Absorption（FCA，自由载流子吸收）；
- 离子注入损伤吸收；
- 缺陷态吸收；
- 掺杂相关吸收；
- 温升导致的吸收增强。

```text
低掺杂漂移层：光传输 + 热缓冲
高掺杂 / 损伤背面层：选择吸收 + 掺杂激活
```

激活深度不再只由表面热扩散决定，而是与掺杂和损伤分布自对准。

---

## SiC — 不让正面经历高温循环，也能形成背面高温接触反应

垂直 SiC 背面欧姆接触需要形成金属硅化物或碳化物等高温反应层。

Cools 让近红外或短波红外光穿过 SiC 本体，并把吸收与发热集中在背面接触形成层或其界面。

该平台同时面向：

- 高局部接触反应温度；
- 低正面热暴露；
- 薄衬底兼容；
- 降低衬底电阻；
- 降低背面接触电阻。

> **热峰形成在 SiC 背面接触界面，而不是光学入射表面。**

---

## GaN — 将宽带隙本体用作光学窗口

在垂直 GaN 器件中，亚带隙光可穿过自支撑 GaN 衬底，并在背面接触金属堆栈中被吸收。

GaN 本体成为主光传输路径，金属或金属–GaN 反应区成为热目标。

对于 GaN-on-Si 结构，专利组合还覆盖去除 Si 手柄衬底，或通过波长和吸收匹配保持背面接触区的主导发热。

> **GaN 衬底成为光学窗口，而不是热源。**

---

## Ga₂O₃ — 同时利用光透射与热约束

Ga₂O₃ 同时具有超宽带隙和低热扩散特性。

在 Cools 架构中：

- Ga₂O₃ 本体透射亚带隙光；
- 背面接触形成层选择性吸收和发热；
- 低热扩散抑制热向正面传播；
- 晶向相关的光吸收和热导各向异性成为工艺匹配变量。

> **Ga₂O₃ 不只是让光通过，也帮助把热限制在背面接触。**

---

## SOI — 将 BOX 从电绝缘层变为退火笼

在 SOI 结构中，BOX 不只是电隔离层。

它承担两个主动工艺功能：

- **光学边界：** 对所选波长具有较低吸收；
- **热学边界：** 低热导抑制热流入手柄衬底。

上部半导体层比 BOX 更强地吸收，而 BOX 将产生的热限制在上部层中。

> **BOX 同时定义光吸收的边界和热激活的约束边界。**

这支持在不使用额外载流子生成光束或预热光束的情况下，以单脉冲选择性激活薄膜和三维集成结构。

## 传统方式与 Cools 方式

| 工艺维度 | 传统表面 / 双光束退火 | Cools 透射式自对准退火 |
|---|---|---|
| 光学入射 | 与加热表面同侧 | 反侧或透射路径 |
| 主吸收位置 | 光首先照射的表面 | 背面接触、掺杂层或损伤层 |
| 热位置决定 | 表面吸收与热扩散 | 材料、掺杂和损伤选择性 |
| 对准方式 | 光学定位与表面几何 | 材料堆栈自对准 |
| 薄化后的正面保护 | 更困难 | 脉冲宽度与入射面–目标面分离控制 |
| 光学系统 | 准分子、绿光、预热或双光束 | 单一亚带隙脉冲或脉冲列可启动加热 |
| 材料范围 | 按材料分别优化 | Si / SiC / GaN / Ga₂O₃ / SOI 共通平台 |
| 功能层 | 可能需要额外吸收层 | 现有阻挡层或接触层可兼作吸收体 |

## 对晶圆厂与器件制造商的价值

该平台旨在实现：

- 正面工艺完成后的低热预算处理；
- 在更薄衬底上形成背面接触；
- 通过衬底薄化和低接触电阻降低垂直器件导通电阻；
- 减少正面栅极、介质与金属化损伤；
- 比载流子生成加热双光束更简单的光学设备；
- 多种半导体材料共用的设备架构；
- 通过吸收分布和脉冲时间控制激活深度，而非只依赖表面热扩散。

> **不要让热穿过晶圆。让光穿过晶圆，并在目标位置产生热。**
